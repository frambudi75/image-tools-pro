## 🔄 Cara Menggunakan Update Otomatis

### Aktifkan Update Otomatis
1. Buka aplikasi Image Tools PRO
2. Klik tab **"Pengaturan"**
3. **Centang** "Aktifkan update otomatis"
4. Pilih frekuensi cek update:
   - **Saat startup**: Cek update setiap buka aplikasi
   - **Harian**: Cek update sekali sehari
   - **Mingguan**: Cek update sekali seminggu

### Update Manual (Jika Perlu)
1. Di tab "Pengaturan", klik tombol **"🔍 Cek Update"**
2. Jika ada versi baru, Anda akan melihat dialog dengan 2 pilihan:
   - **🌐 Kunjungi Web**: Buka halaman download di browser
   - **⬇️ Download Manual**: Download langsung ke folder aplikasi

## ❓ Masalah Umum & Solusi

### 🔴 Update Gagal Download
**Solusi:**
- Pastikan koneksi internet stabil
- Restart aplikasi dan coba lagi
- Coba update manual melalui browser

### 🔴 Aplikasi Tidak Bisa Dibuka Setelah Update
**Solusi:**
- Close aplikasi sepenuhnya (cek di Task Manager)
- Jalankan aplikasi lagi
- Jika masih bermasalah, download ulang dari GitHub

### 🔴 File Backup Hilang
**Solusi:**
- File backup otomatis disimpan di folder `update_backup`
- Jika perlu restore, copy file dari folder tersebut

### 🔴 Update Terlalu Sering
**Solusi:**
- Ubah frekuensi update ke "Mingguan"
- Atau nonaktifkan update otomatis
