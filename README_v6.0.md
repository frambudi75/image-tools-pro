# 📁 Image Tools PRO v6.0 - Folder Contents

## 📋 Overview
Folder ini berisi versi 6.0 dari Image Tools PRO dengan fitur update otomatis dan perbaikan UI.

## 📁 File Contents

### Aplikasi Utama
- `image tools pro v6.exe` - **File executable utama** (jalankan ini untuk menggunakan aplikasi)
- `image tools pro v6.py` - Source code Python (untuk development/debugging)

### File Pendukung
- `image-tools.ico` - Icon aplikasi
- `settings.json` - File pengaturan aplikasi
- `UPDATE_DOCUMENTATION.md` - Dokumentasi teknis lengkap (untuk developer)
- `UPDATE_GUIDE.md` - **Panduan user-friendly** (baca ini dulu!)

### Folder
- `pld/` - Folder untuk file temporary dan backup
- `update_backup/` - Backup file sebelum update

## 🚀 Quick Start

### Untuk User Biasa:
1. **Download** folder ini
2. **Jalankan** `image tools pro v6.exe`
3. **Baca** `UPDATE_GUIDE.md` untuk panduan lengkap

### Untuk Developer:
1. **Install** dependencies dari `requirements.txt`
2. **Jalankan** `python image tools pro v6.py`
3. **Baca** `UPDATE_DOCUMENTATION.md` untuk detail teknis
